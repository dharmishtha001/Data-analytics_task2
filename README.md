# HCAHPS Patient Experience Analytics — Power BI Project

## Overview
End-to-end healthcare business intelligence project analyzing HCAHPS (Hospital Consumer 
Assessment of Healthcare Providers and Systems) survey data to uncover patient experience 
trends across US states and hospitals. Completed as part of a Data Analytics internship, 
in the role of Healthcare Business Intelligence Analyst.

## Tools & Skills
- Power BI (data modeling, DAX, dashboard design)
- Star schema data modeling (4 dimension tables + 3 fact tables)
- DAX (10 measures including RANKX-based rankings, YoY trend calculations)
- Business requirement documentation & KPI definition
- Data quality assessment
- Executive reporting & insights

## Data Model
Star schema built from 7 source tables:
- **Dimensions:** states, measures, questions, reports
- **Facts:** responses, national_results, state_results

## Dashboards (4 pages)
1. Executive Overview
2. State Performance & Benchmark
3. Patient Experience Measures
4. Regional & Trend Analysis

Includes a Decomposition Tree for root-cause analysis on selected metrics.
